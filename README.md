# video-detect-lab
用 C++ 对本地视频文件逐帧或抽帧进行目标检测，生成带检测框的视频、结构化检测结果和性能报告

**章节**

1. 搭建可复现的 C++ 推理环境
2. 用 OpenCV 读取视频，理解帧率、尺寸和帧数
3. ONNX Runtime 单张图片推理
4. 图像预处理与坐标变换
5. 模型输出、置信度过滤与 NMS
6. 把单张图片检测扩展到逐帧视频处理
7. 绘制检测框并输出视频和 JSONL
8. 建立基准测试，分清推理速度和端到速度
9. 抽帧、降低分辨率和线程参数优化
10. 解码、推理和编码并行化
11. 异常处理、资源管理与测试
12. 命令行、配置和可复现交付
