# video-detect-lab

用 C++ 对本地视频文件逐帧或抽帧进行目标检测，生成带检测框的视频、结构化检测结果和性能报告

项目不涉及训练模型，使用的是预训练模型

#### 目标检测和视频理解

**目标检测** 

核心任务是在图像中定位并识别出特定类别的物体，输出其边界框和类别标签。它回答目标**是什么**和**在哪里**的问题。

**视频理解** 

除了识别物体，还要分析物体之间的时空关系，行为运作，事件因果等。它回答的是**在发生什么**和”为什么会这样**的问题。

**视频目标检测的算法演进**

1. Seq-NMS 后处理整合
2. FGFA/MANet 端到端多帧特征融合
3. TransVOD transformer时序建模

**视频理解的技术前沿**

1. C3D/I3D 3D CNN 方法
2. TimeSformer/ViViT Video Transformer

**统一视频模型**

最新趋势是统一的基础模型，同时处理检测、分割、跟踪和视频理解等多类任务。

#### 图像检测和视频逐帧检测的关系

**逻辑关系**

逐帧检测 = 图像检测 + 帧分解

它本质上没有专门为视频设计新模型，而是把视频当成**很多张图片的集合**。因此

- 图像检测：单帧输入，单帧输出
- 视频逐帧检测：多帧输入，但每帧独立处理，帧与帧之间无信息交互
- 视频目标检测：多帧输入，利用帧间时序信息进行特征传播、融合或后处理

**图像检测器**

- YOLO
- Faster R-CNN
- DETR
